# ADR-0007：RAG Evidence 质量门槛

- 状态：Accepted
- 日期：2026-07-25
- 适用版本：V1.8.2-S3

## 背景

真实 Trace 表明，现有 RAG 会让章节标题占用向量 Top-K，并可能把正文弱相关
结果或 RuntimeRelease 的词法 fallback 当成最终 Evidence。模型在证据不足时仍
可能补充知识库外的行业时效和处理步骤。

这是个人面试 Demo 的可信度问题，不需要更换向量库或建设通用 RAG 平台。

## 决策

1. 标题只保留结构意义，必须与其后的第一个事实段落合并；FAQ 问答和表格
   表头/数据行保持同一证据语境。
2. 语义通道先扩大候选，再过滤结构块；最终 Evidence 只按 Chunk 正文相关度
   过门槛并重排，文档标题不能单独推高 Evidence 分数。
3. 明确指定文档时，只将检索范围限制到该文档；正文仍必须通过同一门槛。
4. RuntimeRelease snapshot fallback 使用同一个正文门槛，不能绕过 Evidence
   规则。
5. 制度、时效、收费、权限、流程和安全责任没有合格 Evidence 时，跳过垂直
   模型并返回固定的“当前知识依据不足”答复。
6. 时间、金额、比例和数量必须出现在对应 Citation 的 Chunk 中；校验失败时
   最终回答降级为知识依据不足。
7. 使用固定 12 题小型评估集分别报告 Keyword、Vector、Hybrid、拒答和引用
   正确性。

## 不采用

- 更换向量数据库；
- GraphRAG、Cross-Encoder 或新通用 RAG 框架；
- 通用 Query Planner；
- 全量重建知识库；
- 为单个问题增加硬编码答案或专属关键词。

## 影响

- 未来新增知识文档自动使用新的结构化切片规则；
- 本次只重建维修演示链路绑定且确实受影响的文档；
- 低证据回答会更保守，但不会再把弱相关片段包装成确定性物业规则；
- Trace 记录 Evidence 数量、门槛、fallback 和最终采用/拒绝决定。

## 回滚

回退本 ADR 对应代码版本，并仅对本次受影响文档调用原切片器重新索引；随后
重新发布 RuntimeRelease。文档正文和业务数据不变。
