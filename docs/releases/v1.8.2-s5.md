## 模型身份与 Usage 合同

- `requested_model`：系统实际传给 Provider 的请求模型。
- `provider_response_model`：只读取 Provider 原始 `response.model`；Provider 未返回时保持空值，页面显示“未返回/未采集”。
- `thinking_enabled`：单独保存，Thinking 模式不等于 Pro。
- `prompt_cache_hit_tokens` → `input_cache_hit_tokens`。
- `prompt_cache_miss_tokens` → `input_cache_miss_tokens`。
- `completion_tokens` → `output_tokens`。
- Provider request_id 保存于现有 `usage_normalized` JSON。

来源判定：

- `provider_actual`：Provider 调用成功，且原始三类 Usage 全部存在。
- `estimated`：只有本地估算证据；不会冒充 Provider Usage，也不计算精确供应商费用。
- `unavailable`：Provider 失败、字段缺失、只有 total_tokens、或缺少实际响应模型/匹配价格快照。

历史 total-only 记录保持原貌，不反推、不平均拆分、不回填。
