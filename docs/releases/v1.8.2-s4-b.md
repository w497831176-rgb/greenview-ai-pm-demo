## 运行时阻塞与最小修复

固定问题中的“连续 7 天”是用户提供的计算输入，不是知识文档必须逐字包含的制度
事实。原 Evidence 门槛把所有带单位数字都当作知识主张，导致包含“每个种植舱每天
3 份”的正确 Chunk 被错误过滤。

本轮使用窄规则只识别“连续/持续 + 时长 + 需要/计算”等计算操作数：

- 检索和 Snapshot fallback 不再要求知识证据重复用户给定的 7 天；
- Citation 校验允许答案复述该计算输入；
- 每舱每天 3 份等知识事实仍必须由最终 Evidence 直接支持；
- 3 个工作日与 5 个工作日不一致等既有安全校验保持有效。

未新增 Router 关键词补丁、通用 Planner、数据库、表、框架、模型或外部依赖。
