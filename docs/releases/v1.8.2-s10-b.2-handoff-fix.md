## 变更

- 语义 Router 只在用户真实目的为“停止 AI、由工作人员接手”时输出 `user_requested_handoff`；否定、规则询问和未来可能性不输出该意图。
- 该意图不改变 A/B/C 分类，但会在 Agent、Skill、RAG、Tool、Evidence Gate 和 ActionGateway 之前进入 Handoff Controller。
- Handoff 原因统一为 `user_requested`，新请求、等待领取和已领取分别返回真实状态文案。
- 按钮仍为零模型直达 Handoff，并改为展示后端真实状态；失败响应不会显示成功。
- 同一会话已为 `requested` 时不会重复创建人工协同记录；取消、关闭或结束后仍可按原规则重新发起。
