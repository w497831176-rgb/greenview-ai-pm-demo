# V1.8.2 Target 1 B Controlled-Write Entry

Date: 2026-08-07
RuntimeRelease: `rr_0027_3ec523af / v27` (unchanged)

## Before -> After

- Before: the semantic Router could correctly identify a new repair-order request, but the Coordinator and workflow independently reclassified the Chinese text with a narrow regular expression. A valid request could therefore fall back to consultation with no Draft or Proposal.
- After: the Router emits the reserved intent `work_order_create`; only the exact pair `B_PROPERTY_GOVERNED + work_order_create` authorizes the first Draft. The Coordinator forwards this structured authorization to the workflow without a second natural-language decision.

## Preserved boundaries

- Other B intents, A, C, and non-reserved Chinese intent text cannot start a new work-order workflow.
- Once a Draft or Proposal exists, field collection, cancellation, confirmation, and idempotent replay remain governed by the persisted state machine.
- An incomplete Draft pauses at `draft_updated`; a complete Draft produces a `pending_confirmation` Proposal and pauses at `awaiting_confirmation`.
- An explicitly labelled urgency value (for example, `紧急程度中等`) takes precedence over the word `紧急` inside the field label, so the Proposal preserves the owner's actual value.
- Before owner confirmation there is no Approval, ActionGateway execution, formal work order, or Receipt. MCP remains read-only.
- No database schema, capability configuration, cost accounting, or RuntimeRelease was changed.

## Verification

- Focused deterministic test uses a fresh temporary SQLite database, blocks network access, and records zero Provider attempts.
- The original failing input creates one incomplete Draft and asks for every missing field.
- The complete input creates one Draft plus one pending Proposal while all committed-write effects remain zero.
- Query-only, other B intents, non-reserved Chinese intent, and A/C poisoned decisions cannot create Drafts or Proposals.
- Existing cancellation, explicit confirmation, and repeat-confirmation idempotency remain covered in the temporary database.
