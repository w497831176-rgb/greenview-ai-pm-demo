# V1.8.2-S9-B.2：成本治理时间范围与调用记录分页

## 结果

- 成本治理默认仍显示“今天”，并新增昨天、近7天、本月、上月和自定义日期；所有范围统一按北京时间计算。
- 总览、成本口径、Token、异常判断和调用记录共用同一时间范围，页面文案随范围变化。
- 调用记录改为服务端分页，每页20条、全局按时间倒序；时间或高级筛选变化时回到第1页。
- 聊天、仅模型调用、无模型规则和用量证据缺失四类调用记录保持在同一个去重列表中。

## 边界

- 未修改成本公式、价格、模型路由、历史数据或数据库结构。
- 未调用模型，未发布RuntimeRelease；运行时能力配置继续固定在v26。
- 未恢复图表、独立策略页、高成本排行或其他复杂模块。

## 验证

- 新增无模型确定性合同测试，覆盖六种时间范围、跨月自定义范围、20条服务端分页、去重和四类调用记录。
- 回归S9-B/S9-B.1成本故事合同、S5 Provider Usage与成本合同，并执行前端JavaScript语法检查。
- 页面视觉效果继续由用户手动验收，不使用浏览器自动化。
